# Course Introduction

**Topic:** AI, LLMs, Context, Tools & the MCP Server
**Duration:** ~5 minutes
**Format:** Word-for-word delivery script (pause cues marked in *italics*)

---

Hello and Welcome! 

Have you ever wondered how ChatGPT, Claude Code, or Codex... get the superpowers to do so many things. We all know LLMs have a lot of knowledge acquired during the training time but how does it actually perform so many **actions? How does it check the latest weather, search the web, or create a file on our laptop?



In this session, we're going to start with some foundational knowledge around AI, LLM. And dive deeper on many conceptual topics which will prepare us to understand the MCP (Model Context Protocol) which enables LLMs with super powers through additional tools.



Section-1: **Foundation**

We will start with the absolute core: what is a Large Language Model, and for the first time, we will write the simplest possible programs that talk to an LLM. 



**Section-2: Concepts**

This is the heart of the course, and it's built around one idea: an LLM, by itself, is just a brain in a jar. It's brilliant, but it's isolated. It doesn't know what happened five minutes ago. It doesn't know today's date. It can't check your calendar or run a calculation. So in this section, we solve that, piece by piece.

We will learn about Agent, ChatGPT, Context, Tool Calls and MCP



Section-3**: Build our own MCP Server**

In this section we're going to build our own MCP Server from scratch. A real MCP server, a real client, a real host application talking to it. We will see all of them in action, as an AI interacts through our own MCP Server.

Section-4: Building AI Enabled Incident Assistant

In the final part of this course, we take everything — the model, the context, the tools, the MCP server — and assemble it into something real: a working AI assistant with an actual interface, handling a genuine use case, end to end. Something you could enhance to make it commercial grade application.



So — stick with me till the end. Keep your code editor open, follow along with the code, and don't just watch — build with me. That's where the real learning happens.



Let's get started.
